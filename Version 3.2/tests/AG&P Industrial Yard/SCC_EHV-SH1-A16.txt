💡 FUSE SELECTION TIPS
────────────────────────────────────────────────────────────────────────────────
• Class RK1 or J: Best for motor circuits (time-delay + current limiting)
• Class L: Required for currents above 600A
• Class T: Very fast, use for sensitive electronics
• Current limiting fuses reduce let-through I²t (less damage)
• Consider Class J for best cost/performance balance
